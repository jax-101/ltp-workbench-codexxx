# Goal Tree - LTP Workbench

System: Aplicacion LTP Workbench

## System Profile

- Owner: Usuario principal
- Purpose: Ayudar al usuario a razonar sobre sistemas complejos sin depender de herramientas de diagramacion genericas.
- Boundary: Incluye definicion del sistema, Goal Tree, canvas de arboles, teclado, frames, links con assumptions y guardado local.

## Goal

- LTP Workbench helps the user work through complex system problems with disciplined logical thinking.

## Critical Success Factors

### Logical meaning preserved

The app preserves the logical meaning of the user's reasoning.

Link: In order to achieve disciplined LTP problem solving, the app must preserve the logical meaning of the user's reasoning.

Assumptions:
- A tool that loses assumptions or link meaning cannot reliably support LTP reasoning.

Necessary Conditions:
- Each system has a minimum System Profile.
- The system benchmark is represented as a Goal Tree.
- Each link can expose the assumptions that support it.

### Tree can be built without mouse

The user can construct and edit the tree without using the mouse.

Link: In order to achieve disciplined LTP problem solving, the user must be able to construct and edit the tree without using the mouse.

Assumptions:
- Mouse-heavy construction creates enough friction to interrupt structured thinking.

### Work is recoverable

The user's work can be saved, inspected, reopened, and exported locally.

Link: In order to achieve disciplined LTP problem solving, the user's work must be saved, inspected, reopened, and exported locally.

Assumptions:
- A standalone reasoning tool must keep user work recoverable without relying on external services.
